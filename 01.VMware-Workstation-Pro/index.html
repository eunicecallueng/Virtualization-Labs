01. VMware Workstation Pro Setup

Comprehensive guide on virtual network configuration, host resource allocation, and baseline VM provisioning.

1. Objective & Overview

This lab demonstrates the configuration of a local virtualization environment using VMware Workstation Pro. It serves as the foundation for deploying domain infrastructure, client machines, and network monitoring endpoints.

2. Virtual Network Topology

  • VMnet0 (Bridged): Attached to host physical NIC for external communication.
  • VMnet8 (NAT): Isolated subnet 192.168.10.0/24 for lab environments.
  • Virtual DHCP: Disabled to allow static IP assignment via Windows Server / Active Directory.

3. Provisioned Virtual Machines

  • Windows Server 2022: Primary Domain Controller & DNS Gateway.
  • Windows 11 Workstation: Client endpoint for domain join and policy verification.
  • Linux / Zabbix Server: Dedicated monitoring instance for active network logging.

4. Key Configurations Performed

  • Configured custom virtual switches via Virtual Network Editor.
  • Enabled Intel VT-x / AMD-V hardware acceleration for nested workloads.
  • Set up static MAC addresses and snapshots for state recovery during testing.
